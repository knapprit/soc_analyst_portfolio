1. Сканирование  sudo nmap -Pn -sC -sV <IP машины>

-Pn — HTB-машины часто не отвечают на ping, поэтому говорим nmap "не проверяй доступность хоста, просто сканируй порты"
-sC — запустить стандартные скрипты для получения дополнительной информации о сервисах
-sV — определить версии запущенных сервисов (это критично — нам нужна точная версия)

Обнаружены два открытых порта. Порт 22 (SSH) — стандартный способ удалённого управления Linux-сервером, пока недоступен без credentials. Порт 3000 — здесь работает веб-приложение на Next.js версии 15.0.3. Версия критична: именно она определяет, какие уязвимости применимы.
   
2. Зная версию Next.js (15.0.3), ищем известные уязвимости.

На ExploitDB (exploit-db.com) найдите CVE-2025-55182 — уязвимость класса Remote Code Execution (RCE) в Next.js. Она позволяет выполнять произвольные команды на сервере без аутентификации через механизм React Server Components.
